# paymygig-site
Web pública estática de payMyGig (inicio, política de privacidad y eliminación de cuenta), en HTML y CSS sin build ni JavaScript.
Para verla en local, abre `index.html` en el navegador.
Se publica con GitHub Pages desde la rama `main` con el dominio propio paymygig.es (archivo `CNAME`).
Los datos del titular pendientes aparecen como `[POR CONFIRMAR: ...]`.
